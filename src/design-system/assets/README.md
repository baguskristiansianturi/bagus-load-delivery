# Asset Warehouse

The structured registry is `src/design-system/assets/registry.js`. Search it before adding or replacing any icon, logo, illustration, image or font.

External assets are not automatically approved. Follow `docs/pluits/ASSET-WAREHOUSE-AND-EXTERNAL-ASSET-APPROVAL-SOP.md` and ask the product owner before sourcing outside.

Update the registry in the same change as any asset addition/removal. Check license, role, dimensions, contrast and approved consumers before use.

# PLUITS — Investor & Product Documentation Package
**Tanggal:** 9 November 2026  
**Bahasa:** Indonesia  
**Versi:** 1.0

## Cara membaca
Mulai dari cerita Ibu Nia di proposal investor. Cerita ini menjelaskan alasan PLUITS dibuat dan nilai tambah dibanding kebiasaan sosial yang sudah dikenal. Setelah itu baca model bisnis, dampak ke setiap pihak, GeoDirectory, sumber pendapatan, strategi Bali, teknologi, dan roadmap.

## Isi paket
1. **PLUITS-INVESTOR-PROPOSAL.md** — dokumen untuk memperkenalkan bisnis kepada calon investor.
2. **PLUITS-BUSINESS-AND-PRODUCT-BLUEPRINT.md** — acuan internal yang menghubungkan cerita founder ke journey, algoritma, backend, frontend, keamanan, dan acceptance.
3. **PLUITS-TECHNOLOGY-ROADMAP-AND-AUDIT-2026-11-09.md** — audit repository dan Supabase live, status implementasi, gap, roadmap, estimasi indikatif, dan data yang dibutuhkan untuk budget/ROI.
4. **visuals/** — diagram ekosistem, journey Ibu Nia, alur trust GeoDirectory, mockup feed mobile, arsitektur, dan roadmap.

## Catatan untuk investor
Dokumen ini menjelaskan model dan arah strategis. Market sizing, biaya, headcount, kebutuhan pendanaan, revenue forecast, CAC, LTV, unit economics, break-even, dan ROI belum dimasukkan karena data dasarnya belum diukur. Angka yang belum tervalidasi tidak boleh diperlakukan sebagai proyeksi.

Komisi 2% adalah contoh hipotesis yang pernah dibahas, bukan tarif yang disetujui. Wallet, donasi, affiliate, booking, dan integrasi pemerintah tidak boleh diklaim siap produksi sebelum legal, operasional, keamanan, dan pengujian selesai.

## Catatan internal repository
Business Model Master adalah sumber keputusan aktif. Decision Log mencatat keputusan founder. Idea Backlog menampung workflow yang masih memerlukan riset. Project Status & Roadmap mencatat delivery. Proposal investor tidak menggantikan dokumen internal tersebut.

## Print / export
Untuk cetak, gunakan Markdown yang dirender GitHub atau ekspor dokumen ke PDF. SVG dapat dibuka langsung di browser dan dicetak pada ukuran besar tanpa pecah. Mockup feed adalah konsep visual, bukan klaim bahwa UI produksi saat ini sudah sama.
